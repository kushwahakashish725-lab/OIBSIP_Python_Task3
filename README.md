# Password Generator

## Objective

The objective of this project is to develop a Password Generator that creates strong, random, and secure passwords using a combination of letters, numbers, and special characters.

## Project Description

The Password Generator is a Python-based application that generates random passwords according to the required password length. It uses a combination of uppercase letters, lowercase letters, digits, and special characters to create stronger passwords.

## Features

- Generates random passwords
- Allows the user to specify password length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Creates a different password each time

## Technologies Used

- Python
- Random module
- String module
- User Input and Output

## Steps Performed

1. Imported the required Python modules.
2. Created character sets containing letters, numbers, and special characters.
3. Took the required password length from the user.
4. Combined different character sets.
5. Randomly selected characters to generate the password.
6. Displayed the generated password to the user.

## Outcome

Successfully developed a Python-based Password Generator that creates strong and random passwords using different types of characters.

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the Password Generator Python file.
5. Run the Python program.
6. Enter the desired password length.
7. The generated password will be displayed.
